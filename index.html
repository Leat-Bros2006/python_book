Python Programming 01. Introduction to Python & Setup

01. Introduction to Python & Setup

1. Definition (និយមន័យ):

Python គឺជាភាសាសរសេរកម្មវិធីកម្រិតខ្ពស់ (High-Level Programming Language) ដែលមានរចនាសម្ព័ន្ធកូដខ្លី ងាយស្រួលអាន និងយល់ដូចភាសាអង់គ្លេសធម្មតា សម្រាប់បង្កើត Backend Web (FastAPI, Django), Data Science និង AI។

2. មុខងារសំខាន់ៗ:

  • print() (បង្ហាញលទ្ធផល)៖ ប្រើសម្រាប់បោះពុម្ពអត្ថបទ ឬតម្លៃអថេរចេញមកលើផ្ទាំង Terminal។
  • # (Comment)៖ ប្រើសម្រាប់សរសេរចំណាំពន្យល់កូដ ដោយ Python មិនយកមកដំណើរការឡើយ។
  • Indentation (ការដកឃ្លា 4 spaces)៖ ប្រើសម្រាប់បែងចែកប្លុកកូដជំនួសឱ្យសញ្ញា { }។
  • កន្ទុយឯកសារ .py ៖ រាល់ឯកសារកូដ Python ទាំងអស់ត្រូវរក្សាទុកដោយមានកន្ទុយ .py (ឧ. main.py)។

3. Syntax (ទម្រង់កូដ):

# នេះគឺជា Comment សម្រាប់ពន្យល់កូដ
print("សួស្តីពិភព Python!")
print("ការគណនា៖", 10 + 25)

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python main.py
សួស្តីពិភព Python!
ការគណនា៖ 35
5. Summary (សង្ខេបមេរៀន)៖ Python ប្រើ print() ដើម្បីបង្ហាញលទ្ធផល ប្រើ # សម្រាប់ Comment និងគោរពការដកឃ្លា (Indentation) ឱ្យបានត្រឹមត្រូវ។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 3
Python Programming 02. Python Variables & Naming Rules

02. Python Variables & Naming Rules

1. Definition (និយមន័យ):

Variable (អថេរ) គឺជាប្រអប់ផ្ទុកទិន្នន័យនៅក្នុង Memory របស់កុំព្យូទ័រ។ ក្នុង Python យើងបង្កើតអថេរភ្លាមៗដោយប្រើសញ្ញា = ដើម្បីផ្តល់តម្លៃ ដោយមិនចាំបាច់ប្រកាសប្រភេទទិន្នន័យជាមុនឡើយ។

2. មុខងារសំខាន់ៗ:

  • ចាប់ផ្តើមឈ្មោះអថេរ៖ ត្រូវផ្តើមដោយអក្សរ (a-z, A-Z) ឬសញ្ញា _ ប៉ុណ្ណោះ (ហាមផ្តើមដោយលេខ ឧ. 1user គឺខុស)។
  • ក្បួន snake_case ៖ ហាមដកឃ្លា ឬប្រើសញ្ញាដក - ក្នុងឈ្មោះអថេរ ត្រូវប្រើ _ ភ្ជាប់ពាក្យ (ឧ. student_name)។
  • Case-Sensitive (ប្រកាន់អក្សរធំ-តូច)៖ អថេរ age និង Age គឺជាអថេរពីរផ្សេងគ្នា។
  • Multiple Assignment៖ អាចផ្តល់តម្លៃឱ្យអថេរច្រើនក្នុងបន្ទាត់តែមួយ (ឧ. x, y = 10, 20)។

3. Syntax (ទម្រង់កូដ):

student_name = "លាត ប្រុស"
student_age = 20
x, y = 10, 20

# កែប្រែតម្លៃថ្មីឱ្យអថេរចាស់
student_age = 21
print(student_name, "| អាយុថ្មី៖", student_age, "| x+y =", x + y)

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python variables.py
លាត ប្រុស | អាយុថ្មី៖ 21 | x+y = 30
5. Summary (សង្ខេបមេរៀន)៖ ត្រូវដាក់ឈ្មោះអថេរឱ្យមានអត្ថន័យច្បាស់លាស់តាមក្បួន snake_case និងចៀសវាងប្រើពាក្យគន្លឹះរបស់ Python ដូចជា if, for, class មកធ្វើជាឈ្មោះអថេរ។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 4
Python Programming 03. Python Data Types & Type Casting

03. Python Data Types & Type Casting (Detail)

1. Definition (និយមន័យ):

Data Types (ប្រភេទទិន្នន័យ) គឺជាការបែងចែកប្រភេទតម្លៃដែលអថេរនីមួយៗផ្ទុក ដើម្បីឱ្យ Python ដឹងថាត្រូវយកវាទៅគណនា ឬភ្ជាប់អត្ថបទតាមរបៀបណា។

2. មុខងារសំខាន់ៗ:

  • str (String)៖ ផ្ទុកទិន្នន័យជាអត្ថបទ ឬតួអក្សរ សរសេរក្នុង "..." ឬ '...' (ឧ. "Hello")។
  • int (Integer)៖ ផ្ទុកទិន្នន័យជាលេខចំនួនគត់ ទាំងវិជ្ជមាន និងអវិជ្ជមាន គ្មានក្បៀស (ឧ. 100, -25)។
  • float (Floating Point)៖ ផ្ទុកទិន្នន័យជាលេខទសភាគ ដែលមានចំណុចក្បៀស (ឧ. 19.99, 3.14)។
  • bool (Boolean)៖ ផ្ទុកតម្លៃតក្កវិទ្យា មានតែ ២ គត់គឺ True (ពិត) និង False (មិនពិត)។
  • NoneType (None)៖ តំណាងឱ្យភាពទទេ ឬគ្មានតម្លៃអ្វីទាំងអស់ (data = None)។
  • type() & Type Casting (int(), float(), str())៖ ពិនិត្យប្រភេទទិន្នន័យ និងបម្លែងប្រភេទទិន្នន័យពីមួយទៅមួយ។

3. Syntax (ទម្រង់កូដ):

text = "Python"          # str
qty = 5                  # int
price = 12.50            # float
is_active = True         # bool
empty_val = None         # NoneType

# Type Casting: បម្លែងអក្សរ "100" ទៅជា int ដើម្បីបូកលេខ
result = int("100") + qty
print(type(price), type(is_active), "| Result:", result)

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python datatypes.py
<class 'float'> <class 'bool'> | Result: 105
5. Summary (សង្ខេបមេរៀន)៖ Python មិនអនុញ្ញាតឱ្យយក str ទៅបូកជាមួយ int ដោយផ្ទាល់ទេ ត្រូវប្រើ int() ឬ float() បម្លែងជាមុនសិន។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 5
Python Programming 04. User Input & String Formatting

04. User Input & String Formatting (f-strings)

1. Definition (និយមន័យ):

input() ប្រើសម្រាប់ទទួលទិន្នន័យពីអ្នកប្រើប្រាស់តាម Keyboard ហើយ f-string (f"...") ប្រើសម្រាប់បញ្ចូលអថេរទៅក្នុងអត្ថបទយ៉ាងខ្លី និងស្អាតបំផុត។

2. មុខងារសំខាន់ៗ:

  • input() (ទទួលទិន្នន័យ)៖ ផ្តល់តម្លៃជា str ជានិច្ច ត្រូវបម្លែងជា int() បើចង់គណនាលេខ។
  • f"{variable}" (f-string)៖ ដាក់អក្សរ f នៅខាងមុខធ្មេញកណ្តុរ ដើម្បីបង្ហាញតម្លៃអថេរក្នុង { }។
  • .strip() (សម្អាតដកឃ្លា)៖ លុបចន្លោះដកឃ្លាដែលលើសនៅខាងដើម និងខាងចុងអត្ថបទ។
  • .upper() & .lower() ៖ បម្លែងអត្ថបទទៅជាអក្សរធំទាំងអស់ ឬអក្សរតូចទាំងអស់។

3. Syntax (ទម្រង់កូដ):

name = input("បញ្ចូលឈ្មោះរបស់អ្នក៖ ").strip()
birth_year = int(input("បញ្ចូលឆ្នាំកំណើត៖ "))
age = 2026 - birth_year
print(f"សួស្តី {name}! នៅឆ្នាំ ២០២៦ អ្នកមានអាយុ {age} ឆ្នាំហើយ។")

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python age_calc.py
បញ្ចូលឈ្មោះរបស់អ្នក៖ ដារ៉ា | បញ្ចូលឆ្នាំកំណើត៖ 2005
សួស្តី ដារ៉ា! នៅឆ្នាំ ២០២៦ អ្នកមានអាយុ 21 ឆ្នាំហើយ។
5. Summary (សង្ខេបមេរៀន)៖ ត្រូវចាំថា input() ផ្តល់តម្លៃជា str ជានិច្ច ហើយប្រើ f"..." ដើម្បីភ្ជាប់អថេរជាមួយអត្ថបទ។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 6
Python Programming 05. Arithmetic & Assignment Operators

05. Arithmetic & Assignment Operators

1. Definition (និយមន័យ):

Arithmetic Operators ប្រើសម្រាប់ធ្វើប្រមាណវិធីគណិតវិទ្យា រីឯ Assignment Operators ប្រើសម្រាប់ផ្តល់ និងបូកបន្ថែមតម្លៃឱ្យអថេរដោយសរសេរកាត់ខ្លី។

2. មុខងារសំខាន់ៗ:

  • +, -, *, / ៖ បូក ដក គុណ និងចែកយកទសភាគ (ឧ. 10 / 3 = 3.333...)។
  • // (Floor Division)៖ ចែកយកតែចំនួនគត់ កាត់ក្បៀសចោល (ឧ. 10 // 3 = 3)។
  • % (Modulus)៖ ចែកយកសំណល់ (ឧ. 10 % 3 = 1)។
  • ** (Exponentiation)៖ លើកជាស្វ័យគុណ (ឧ. 2 ** 3 = 8)។
  • +=, -=, *=, /= (Assignment)៖ សរសេរកាត់ (ឧ. x += 5 មានន័យស្មើនឹង x = x + 5)។

3. Syntax (ទម្រង់កូដ):

a, b = 10, 3
print("ចែកគត់ (//)៖", a // b, "| សំណល់ (%)៖", a % b, "| ស្វ័យគុណ (**)៖", a ** b)

score = 50
score += 15   # បូកបន្ថែម 15 ចូលក្នុង score
print("ពិន្ទុបន្ទាប់ពី += 15៖", score)

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python arithmetic.py
ចែកគត់ (//)៖ 3 | សំណល់ (%)៖ 1 | ស្វ័យគុណ (**)៖ 1000
ពិន្ទុបន្ទាប់ពី += 15៖ 65
5. Summary (សង្ខេបមេរៀន)៖ សញ្ញា / តែងតែផ្តល់លទ្ធផលជា float ជានិច្ច ទោះបីចែកដាច់ក៏ដោយ (ឧ. 10 / 2 = 5.0)។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 7
Python Programming 06. Comparison & Logical Operators

06. Comparison & Logical Operators

1. Definition (និយមន័យ):

Comparison Operators ប្រើសម្រាប់ប្រៀបធៀបតម្លៃពីរ រីឯ Logical Operators ប្រើសម្រាប់ភ្ជាប់លក្ខខណ្ឌច្រើនចូលគ្នា ដោយលទ្ធផលតែងតែចេញជា True ឬ False ជានិច្ច។

2. មុខងារសំខាន់ៗ:

  • == (Equal to)៖ ពិនិត្យថាតើតម្លៃទាំងពីរស្មើគ្នាឬអត់ (ឧ. 5 == 5 គឺ True)។
  • != (Not Equal to)៖ ពិនិត្យថាតើតម្លៃទាំងពីរខុសគ្នាឬអត់ (ឧ. 5 != 3 គឺ True)។
  • >, <, >=, <= ៖ ធំជាង តូចជាង ធំជាងឬស្មើ និងតូចជាងឬស្មើ។
  • and (និង)៖ ផ្តល់ True លុះត្រាតែលក្ខខណ្ឌទាំងសងខាងពិតទាំងពីរ។
  • or (ឬ)៖ ផ្តល់ True ប្រសិនបើមានលក្ខខណ្ឌយ៉ាងតិចមួយពិត។
  • not (មិនមែន)៖ បញ្ច្រាសលទ្ធផលពី True ទៅ False និងពី False ទៅ True។

3. Syntax (ទម្រង់កូដ):

x, y = 10, 20
print("x == y:", x == y, "| x != y:", x != y, "| x < y:", x < y)

age = 20
has_id = True
print("អាចបើកបរបាន (and):", age >= 18 and has_id)
print("បញ្ច្រាស (not):", not has_id)

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python comparison.py
x == y: False | x != y: True | x < y: True
អាចបើកបរបាន (and): True | បញ្ច្រាស (not): False
5. Summary (សង្ខេបមេរៀន)៖ Comparison និង Logical Operators គឺជាគ្រឹះដ៏សំខាន់បំផុតសម្រាប់យកទៅសរសេរលក្ខខណ្ឌក្នុង if / elif / else និង while loop។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 8
Python Programming 07. Conditional Statements

07. Conditional Statements (if, elif, else)

1. Definition (និយមន័យ):

Conditional Statements ប្រើសម្រាប់ឱ្យកម្មវិធីធ្វើការសម្រេចចិត្តដំណើរការកូដផ្សេងៗគ្នា ដោយផ្អែកលើលក្ខខណ្ឌពិត (True) ឬមិនពិត (False)។

2. មុខងារសំខាន់ៗ:

  • if (ប្រសិនបើ)៖ ពិនិត្យលក្ខខណ្ឌទី ១ បើពិតនឹងដំណើរការកូដខាងក្នុង។
  • elif (ផ្ទុយទៅវិញ ប្រសិនបើ)៖ ពិនិត្យលក្ខខណ្ឌបន្ទាប់ នៅពេលលក្ខខណ្ឌខាងលើមិនពិត។
  • else (ក្រៅពីនេះ)៖ ដំណើរការនៅពេលគ្រប់លក្ខខណ្ឌខាងលើមិនពិតទាំងអស់។
  • សញ្ញា : និង Indentation ៖ ត្រូវដាក់សញ្ញាចុចពីរនៅចុងលក្ខខណ្ឌ និងចុច Tab មុនសរសេរកូដខាងក្នុង។

3. Syntax (ទម្រង់កូដ):

score = 85
if score >= 90:
    print("និទ្ទេស A")
elif score >= 80:
    print("និទ្ទេស B")
elif score >= 50:
    print("និទ្ទេស C (ជាប់)")
else:
    print("ធ្លាក់")

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python grade.py
និទ្ទេស B
5. Summary (សង្ខេបមេរៀន)៖ លក្ខខណ្ឌ if / elif / else ដំណើរការពីលើចុះក្រោម ហើយពេលជួបលក្ខខណ្ឌពិតមុនគេ វានឹងអនុវត្តភ្លាម។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 9
Python Programming 08. Loops in Python

08. Loops in Python (for, while, break, continue)

1. Definition (និយមន័យ):

Loop គឺជាការបញ្ជាឱ្យកូដដំណើរការដដែលៗដោយស្វ័យប្រវត្តិ រហូតដល់ចប់ចំនួនជុំដែលបានកំណត់ ឬលក្ខខណ្ឌលែងពិត។

2. មុខងារសំខាន់ៗ:

  • for loop ៖ រត់តាមចំនួនជុំ range(start, stop, step) ឬទាញទិន្នន័យម្តងមួយៗចេញពី List។
  • while loop ៖ រត់ដដែលៗដរាបណាលក្ខខណ្ឌនៅតែពិត (True)។
  • break ៖ បញ្ឈប់ និងផ្តាច់ចេញពី Loop ទាំងស្រុងមុនពេលចប់ជុំ។
  • continue ៖ រំលងកូដខាងក្រោមក្នុងជុំបច្ចុប្បន្ន ហើយលោតទៅជុំបន្ទាប់។

3. Syntax (ទម្រង់កូដ):

for i in range(1, 6):
    if i == 3: continue  # រំលងលេខ 3
    print(f"ជុំទី {i}")

count = 1
while count <= 2:
    print("While:", count)
    count += 1

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python loops.py
ជុំទី 1 | ជុំទី 2 | ជុំទី 4 | ជុំទី 5
While: 1 | While: 2
5. Summary (សង្ខេបមេរៀន)៖ ប្រើ for ពេលដឹងចំនួនជុំច្បាស់លាស់ និងប្រើ while ពេលរង់ចាំលក្ខខណ្ឌណាមួយកើតឡើង។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 10
Python Programming 09. Python Lists

09. Python Lists & List Comprehension

1. Definition (និយមន័យ):

List គឺជាបញ្ជីផ្ទុកទិន្នន័យច្រើនក្នុងអថេរតែមួយ ដោយប្រើសញ្ញាគ្នាប [ ] មានលំដាប់ (Ordered) និងអាចកែប្រែតម្លៃបាន (Mutable)។

2. មុខងារសំខាន់ៗ:

  • Index (ទីតាំងទិន្នន័យ)៖ រាប់ចាប់ពី 0 (ធាតុទី ១) និង -1 (ធាតុចុងក្រោយ)។
  • .append(item) ៖ បន្ថែមធាតុថ្មីទៅចុងបញ្ចប់នៃ List។
  • .insert(index, item) ៖ បញ្ចូលធាតុថ្មីតាមទីតាំង Index កំណត់។
  • .remove(item) & .pop() ៖ លុបធាតុតាមតម្លៃ ឬលុបធាតុចុងក្រោយ។
  • List Comprehension៖ បង្កើត List ថ្មីក្នុង ១ បន្ទាត់យ៉ាងខ្លី។

3. Syntax (ទម្រង់កូដ):

courses = ["HTML", "CSS", "Python"]
courses.append("React")

nums = [1, 2, 3, 4]
doubled = [n * 2 for n in nums]
print("Courses:", courses, "| Doubled:", doubled)

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python lists.py
Courses: ['HTML', 'CSS', 'Python', 'React'] | Doubled: [2, 4, 6, 8]
5. Summary (សង្ខេបមេរៀន)៖ List ប្រើ [ ] ជាប្រភេទទិន្នន័យដែលប្រើញឹកញាប់បំផុត ហើយ Index ដំបូងតែងតែចាប់ផ្តើមពីលេខ 0។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 11
Python Programming 10. Tuples & Sets

10. Tuples & Sets

1. Definition (និយមន័យ):

Tuple គឺជាបញ្ជីថេរមិនអាចកែប្រែបាន (Immutable) រីឯ Set គឺជាបញ្ជីគ្មានលំដាប់ និងមិនឱ្យមានតម្លៃស្ទួនគ្នា (Unique)។

2. មុខងារសំខាន់ៗ:

  • tuple () (ទិន្នន័យថេរ)៖ បង្កើតហើយមិនអាចបន្ថែម លុប ឬកែតម្លៃខាងក្នុងបានឡើយ ដំណើរការលឿនជាង List។
  • set {} (ទិន្នន័យមិនស្ទួន)៖ លុបទិន្នន័យដែលស្ទួនគ្នាចោលដោយស្វ័យប្រវត្តិ។
  • .union() & .intersection() ៖ ប្រើសម្រាប់បូកបញ្ចូលគ្នា ឬរកចំណុចរួមរវាង Set ពីរ។

3. Syntax (ទម្រង់កូដ):

coordinates = (13.3633, 103.8564)
emails = {"a@mail.com", "b@mail.com", "a@mail.com"}

print("Lat:", coordinates[0])
print("Unique Emails:", emails)

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python tuple_set.py
Lat: 13.3633
Unique Emails: {'a@mail.com', 'b@mail.com'}
5. Summary (សង្ខេបមេរៀន)៖ ប្រើ Tuple () សម្រាប់ទិន្នន័យថេរ និងប្រើ Set {} ពេលចង់ច្រោះលុបទិន្នន័យស្ទួនចេញពីបញ្ជី។

Python Programming 11. Python Dictionaries

11. Python Dictionaries (Key-Value Pairs)

1. Definition (និយមន័យ):

Dictionary គឺជារចនាសម្ព័ន្ធផ្ទុកទិន្នន័យជាគូ Key: Value នៅក្នុងសញ្ញា { } ដូចគ្នាទៅនឹង Object ក្នុង JavaScript ឬ JSON ដែរ។

2. មុខងារសំខាន់ៗ:

  • dict["key"] (ទាញតម្លៃ)៖ ទាញយកតម្លៃតាមឈ្មោះ Key ដោយផ្ទាល់។
  • dict.get("key") (ទាញតម្លៃដោយសុវត្ថិភាព)៖ មិនបង្កើត Error ទេនៅពេលរកឈ្មោះ Key មិនឃើញ។
  • dict["key"] = val (បន្ថែម/កែប្រែ)៖ បន្ថែម Key ថ្មី ឬកែប្រែតម្លៃចាស់។
  • .items() (ទាញទាំងគូ)៖ ទាញយកទាំង Key និង Value ដើម្បីប្រើជាមួយ for loop។

3. Syntax (ទម្រង់កូដ):

student = {"name": "សុខ ដារ៉ា", "course": "Python", "score": 92}
student["city"] = "Siem Reap"

for k, v in student.items():
    print(f"{k}: {v}")

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python dict_demo.py
name: សុខ ដារ៉ា | course: Python | score: 92 | city: Siem Reap
5. Summary (សង្ខេបមេរៀន)៖ Dictionary ប្រើ { "key": value } សម្រាប់ផ្ទុកព័ត៌មានជា Object និងជាគ្រឹះសម្រាប់ធ្វើការជាមួយ JSON API។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 13
Python Programming 12. Functions, Parameters & Return

12. Functions, Parameters & Return Values

1. Definition (និយមន័យ):

Function (អនុគមន៍) គឺជាប្លុកកូដដែលត្រូវបានបង្កើតឡើងដើម្បីបំពេញការងារជាក់លាក់ណាមួយ ហើយអាចហៅយកមកប្រើឡើងវិញបានច្រើនដង (DRY)។

2. មុខងារសំខាន់ៗ:

  • def function_name(): (បង្កើតអនុគមន៍)៖ ប្រើពាក្យគន្លឹះ def ដើម្បីប្រកាសអនុគមន៍។
  • Parameters (តម្លៃទទួលចូល)៖ អថេរក្នុងវង់ក្រចកសម្រាប់ទទួលទិន្នន័យមកគណនា។
  • Default Parameter៖ កំណត់តម្លៃលំនាំដើមទុកជាមុន (ឧ. discount=0)។
  • return (បញ្ជូនលទ្ធផល)៖ បញ្ជូនតម្លៃចេញពីអនុគមន៍ត្រឡប់មកវិញ ដើម្បីយកទៅប្រើបន្ត។

3. Syntax (ទម្រង់កូដ):

def calculate_total(price, qty, discount=0):
    return (price * qty) - discount

bill = calculate_total(25, 3, discount=5)
print(f"ទឹកប្រាក់ត្រូវបង់៖ ${bill}")

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python functions.py
ទឹកប្រាក់ត្រូវបង់៖ $70
5. Summary (សង្ខេបមេរៀន)៖ បង្កើតអនុគមន៍ដោយ def ប្រើ return ដើម្បីទទួលយកលទ្ធផលទៅប្រើបន្ត។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 14
Python Programming 13. *args, **kwargs & Lambda Functions

13. *args, **kwargs & Lambda Functions

1. Definition (និយមន័យ):

អ្នកអាចបង្កើតអនុគមន៍ដែលទទួលតម្លៃចូលមិនកំណត់ចំនួនដោយប្រើ *args និង **kwargs ព្រមទាំងសរសេរអនុគមន៍ខ្លី ១ បន្ទាត់ដោយប្រើ lambda។

2. មុខងារសំខាន់ៗ:

  • *args (Non-Keyword Arguments)៖ ទទួលតម្លៃចូលច្រើនមិនកំណត់ចំនួន ហើយចងក្រងទុកជា Tuple។
  • **kwargs (Keyword Arguments)៖ ទទួលតម្លៃជាគូ key=value ច្រើនមិនកំណត់ ហើយទុកជា Dictionary។
  • lambda args: expr (អនុគមន៍ ១ បន្ទាត់)៖ អនុគមន៍គ្មានឈ្មោះ និយមប្រើជាមួយ map() និង filter()។

3. Syntax (ទម្រង់កូដ):

def sum_all(*numbers):
    return sum(numbers)

square = lambda x: x ** 2
print("Sum:", sum_all(10, 20, 30), "| Square:", square(5))

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python adv_func.py
Sum: 60 | Square: 25

1. Definition (និយមន័យ):

2. មុខងារសំខាន់ៗ:

  • try: (សាកល្បងកូដ)៖ ដាក់កូដដែលអាចនឹងកើតមានបញ្ហា។
  • except ErrorType: (ចាប់កំហុស)៖ ដំណើរការនៅពេលមាន Error កើតឡើងក្នុងប្លុក try។
  • finally: (បញ្ចប់ជានិច្ច)៖ តែងតែដំណើរការជានិច្ច មិនថាមាន Error ឬអត់ឡើយ។

3. Syntax (ទម្រង់កូដ):

try:
    num = int("abc")

    print("កំហុស៖ សូមបញ្ចូលតែលេខប៉ុណ្ណោះ!")
finally:
    print("បញ្ចប់ការត្រួតពិនិត្យ។")

Terminal: python error_handle.py

5. Summary (សង្ខេបមេរៀន)៖ ត្រូវប្រើ try...except ជានិច្ចនៅពេលទទួលទិន្នន័យពី User បើកឯកសារ ឬភ្ជាប់ទៅកាន់ API និង Database។

Python Programming 17. OOP Part 1: Classes & Objects

17. OOP Part 1: Classes, Objects & __init__

1. Definition (និយមន័យ):

OOP (Object-Oriented Programming) គឺជារបៀបសរសេរកម្មវិធីដោយចងក្រងទិន្នន័យ (Attributes) និងមុខងារ (Methods) ចូលគ្នាជាវត្ថុ (Object) តាមរយៈគំរូដើម Class។

2. មុខងារសំខាន់ៗ:

  • class ClassName: (ពុម្ពគំរូ)៖ ឈ្មោះ Class ត្រូវសរសេរអក្សរធំខាងដើម (PascalCase)។
  • __init__(self, ...) (Constructor)៖ អនុគមន៍ពិសេសដែលដំណើរការដោយស្វ័យប្រវត្តិពេលបង្កើត Object ថ្មី។
  • self (តំណាង Object)៖ តំណាងឱ្យ Object បច្ចុប្បន្នដែលកំពុងត្រូវបានហៅប្រើ។

3. Syntax (ទម្រង់កូដ):

class Student:

s1 = Student("សុខា", "Web & Python")

5. Summary (សង្ខេបមេរៀន)៖ Class គឺជាពុម្ពគំរូ រីឯ Object គឺជាវត្ថុពិតដែលកើតចេញពី Class នោះ ហើយគ្រប់ Method ត្រូវតែមាន self ជា Parameter ទី ១។

Python Programming 18. OOP Part 2: Inheritance & Polymorphism

18. OOP Part 2: Inheritance & Polymorphism

1. Definition (និយមន័យ):

Inheritance (ការស្នងមរតក) អនុញ្ញាតឱ្យ Child Class ទទួលយកលក្ខណៈសម្បត្តិពី Parent Class មកប្រើ។ Polymorphism គឺជាការកែប្រែ Method ដូចគ្នាឱ្យដំណើរការខុសគ្នាតាមប្រភេទ Class។

2. មុខងារសំខាន់ៗ:

  • class Child(Parent): (ស្នងមរតក)៖ ដាក់ឈ្មោះ Parent Class ក្នុងវង់ក្រចកដើម្បីទទួលយក Attributes & Methods។
  • super().__init__(...) ៖ ហៅ Constructor របស់ Parent Class មកប្រើក្នុង Child Class។
  • Method Overriding៖ សរសេរ Method ឈ្មោះដូច Parent ក្នុង Child Class ដើម្បីផ្លាស់ប្តូរឥរិយាបថវា។

3. Syntax (ទម្រង់កូដ):

class User:
    def __init__(self, username): self.username = username
    def role(self): return "សិស្សទូទៅ"

class Instructor(User):
    def role(self): return f"គ្រូបង្រៀន៖ {self.username}"

admin = Instructor("លាត ប្រុស")
print(admin.role())

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python inheritance.py
គ្រូបង្រៀន៖ លាត ប្រុស
5. Summary (សង្ខេបមេរៀន)៖ Inheritance កាត់បន្ថយការសរសេរកូដស្ទួន និងប្រើ super() នៅពេលចង់បន្ថែម Attributes ថ្មីក្នុង Child Class។

Python Programming 19. OOP Part 3: Encapsulation & Magic Methods

19. OOP Part 3: Encapsulation & Magic Methods

1. Definition (និយមន័យ):

Encapsulation គឺជាការលាក់ និងការពារទិន្នន័យសំខាន់ៗក្នុង Class កុំឱ្យកែប្រែផ្ទាល់ពីខាងក្រៅ។ រីឯ Magic Methods គឺជាអនុគមន៍ពិសេសដែលមានសញ្ញា __ ខាងមុខ និងក្រោយ។

2. មុខងារសំខាន់ៗ:

  • self.__balance (Private Attribute)៖ ដាក់ __ ខាងមុខឈ្មោះអថេរ ដើម្បីការពារមិនឱ្យហៅកែផ្ទាល់ពីក្រៅ Class។
  • __str__(self) (បង្ហាញអត្ថបទ Object)៖ កំណត់អត្ថបទដែលត្រូវបង្ហាញនៅពេលប្រើ print(object)។
  • __len__(self) (វាស់ប្រវែង)៖ កំណត់តម្លៃពេលប្រើ len(object)។

3. Syntax (ទម្រង់កូដ):

class BankAccount:
    def __init__(self, owner, balance):
        self.owner = owner
        self.__balance = balance   # Private

    def deposit(self, amount):
        if amount > 0: self.__balance += amount

    def __str__(self):
        return f"គណនី៖ {self.owner} | សមតុល្យ៖ ${self.__balance}"

acc = BankAccount("ដារ៉ា", 100)
acc.deposit(50)
print(acc)

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python encapsulation.py
គណនី៖ ដារ៉ា | សមតុល្យ៖ $150
5. Summary (សង្ខេបមេរៀន)៖ ប្រើ __attribute ដើម្បីការពារសុវត្ថិភាពទិន្នន័យ ហើយបង្កើត Method ត្រឹមត្រូវសម្រាប់កែប្រែវា។

20. Decorators & Generators (Advanced Python)

1. Definition (និយមន័យ):

Decorator (@decorator) គឺជាអនុគមន៍ដែលរុំព័ទ្ធអនុគមន៍មួយទៀត ដើម្បីបន្ថែមមុខងារពិសេសដោយមិនបាច់កែកូដខាងក្នុងអនុគមន៍ដើម។ រីឯ Generator ប្រើ yield ដើម្បីបង្កើតទិន្នន័យម្តងមួយៗ សន្សំសំចៃ Memory។

2. មុខងារសំខាន់ៗ:

  • @wrapper_name (Decorator)៖ ប្រើច្រើនបំផុតក្នុង Web Frameworks ដូចជា FastAPI និង Flask (ឧ. @app.get("/"))។
  • yield (Generator)៖ បញ្ជូនតម្លៃម្តងមួយៗពេលត្រូវការ ជំនួស return។

3. Syntax (ទម្រង់កូដ):

def log_decorator(func):
    def wrapper():
        print("[LOG] ចាប់ផ្តើមដំណើរការ...")
        func()
    return wrapper

@log_decorator
def say_hello():
    print("សួស្តី Python Developer!")

say_hello()

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python decorator.py
[LOG] ចាប់ផ្តើមដំណើរការ...

5. Summary (សង្ខេបមេរៀន)៖ Decorators (@) ជួយបន្ថែមមុខងារ Log ឬ Authentication លើអនុគមន៍បានយ៉ាងស្អាត។

22. Database Integration (SQLite / MySQL CRUD)

1. Definition (និយមន័យ):

Python មាន Module sqlite3 ភ្ជាប់មកជាមួយស្រាប់សម្រាប់គ្រប់គ្រង Database និងអនុវត្តប្រតិបត្តិការ CRUD (Create, Read, Update, Delete) ដោយប្រើភាសា SQL។

2. មុខងារសំខាន់ៗ:

  • sqlite3.connect("school.db") ៖ បង្កើត ឬភ្ជាប់ទៅកាន់ឯកសារ Database។
  • cursor.execute(sql, params) ៖ ដំណើរការពាក្យបញ្ជា SQL (ប្រើ ? ដើម្បីការពារ SQL Injection)។
  • conn.commit() ៖ រក្សាទុកការផ្លាស់ប្តូរចូល Database ជាអចិន្ត្រៃយ៍។
  • cur.fetchall() ៖ ទាញយកទិន្នន័យទាំងអស់ដែលបាន Query ចេញពី Database។

3. Syntax (ទម្រង់កូដ):

import sqlite3
conn = sqlite3.connect("school.db")
cur = conn.cursor()

cur.execute("CREATE TABLE IF NOT EXISTS students (id INTEGER PRIMARY KEY, name TEXT)")
cur.execute("INSERT INTO students (name) VALUES (?)", ("លាត ប្រុស",))
conn.commit()

cur.execute("SELECT * FROM students")
print("ទិន្នន័យក្នុង DB៖", cur.fetchall())
conn.close()

ទិន្នន័យក្នុង DB៖ [(1, 'លាត ប្រុស')]
5. Summary (សង្ខេបមេរៀន)៖ ត្រូវហៅ conn.commit() រាល់ពេល INSERT, UPDATE ឬ DELETE ទិន្នន័យ ហើយត្រូវប្រើ Parameterized Query (?) ដើម្បីសុវត្ថិភាព។
