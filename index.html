Python Programming 01. Introduction to Python & Setup

01. Introduction to Python & Setup

1. Definition (និយមន័យ):

Python គឺជាភាសាសរសេរកម្មវិធីកម្រិតខ្ពស់ (High-Level Programming Language) ដែលមានរចនាសម្ព័ន្ធកូដខ្លី ងាយស្រួលអាន និងយល់ដូចភាសាអង់គ្លេសធម្មតា សម្រាប់បង្កើត Backend Web (FastAPI, Django), Data Science និង AI។

2. មុខងារសំខាន់ៗ:

  • print() (បង្ហាញលទ្ធផល)៖ ប្រើសម្រាប់បោះពុម្ពអត្ថបទ ឬតម្លៃអថេរចេញមកលើផ្ទាំង Terminal។
  • # (Comment)៖ ប្រើសម្រាប់សរសេរចំណាំពន្យល់កូដ ដោយ Python មិនយកមកដំណើរការឡើយ។
  • Indentation (ការដកឃ្លា 4 spaces)៖ ប្រើសម្រាប់បែងចែកប្លុកកូដជំនួសឱ្យសញ្ញា { }។
  • កន្ទុយឯកសារ .py ៖ រាល់ឯកសារកូដ Python ទាំងអស់ត្រូវរក្សាទុកដោយមានកន្ទុយ .py (ឧ. main.py)។

3. Syntax (ទម្រង់កូដ):

# នេះគឺជា Comment សម្រាប់ពន្យល់កូដ
print("សួស្តីពិភព Python!")
print("ការគណនា៖", 10 + 25)

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python main.py
សួស្តីពិភព Python!
ការគណនា៖ 35
5. Summary (សង្ខេបមេរៀន)៖ Python ប្រើ print() ដើម្បីបង្ហាញលទ្ធផល ប្រើ # សម្រាប់ Comment និងគោរពការដកឃ្លា (Indentation) ឱ្យបានត្រឹមត្រូវ។

Python Programming 02. Python Variables & Naming Rules

02. Python Variables & Naming Rules

1. Definition (និយមន័យ):

Variable (អថេរ) គឺជាប្រអប់ផ្ទុកទិន្នន័យនៅក្នុង Memory របស់កុំព្យូទ័រ។ ក្នុង Python យើងបង្កើតអថេរភ្លាមៗដោយប្រើសញ្ញា = ដើម្បីផ្តល់តម្លៃ ដោយមិនចាំបាច់ប្រកាសប្រភេទទិន្នន័យជាមុនឡើយ។

2. មុខងារសំខាន់ៗ:

  • ចាប់ផ្តើមឈ្មោះអថេរ៖ ត្រូវផ្តើមដោយអក្សរ (a-z, A-Z) ឬសញ្ញា _ ប៉ុណ្ណោះ (ហាមផ្តើមដោយលេខ ឧ. 1user គឺខុស)។
  • ក្បួន snake_case ៖ ហាមដកឃ្លា ឬប្រើសញ្ញាដក - ក្នុងឈ្មោះអថេរ ត្រូវប្រើ _ ភ្ជាប់ពាក្យ (ឧ. student_name)។
  • Case-Sensitive (ប្រកាន់អក្សរធំ-តូច)៖ អថេរ age និង Age គឺជាអថេរពីរផ្សេងគ្នា។
  • Multiple Assignment៖ អាចផ្តល់តម្លៃឱ្យអថេរច្រើនក្នុងបន្ទាត់តែមួយ (ឧ. x, y = 10, 20)។

3. Syntax (ទម្រង់កូដ):

student_name = "លាត ប្រុស"
student_age = 20
x, y = 10, 20

# កែប្រែតម្លៃថ្មីឱ្យអថេរចាស់
student_age = 21
print(student_name, "| អាយុថ្មី៖", student_age, "| x+y =", x + y)

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python variables.py
លាត ប្រុស | អាយុថ្មី៖ 21 | x+y = 30
5. Summary (សង្ខេបមេរៀន)៖ ត្រូវដាក់ឈ្មោះអថេរឱ្យមានអត្ថន័យច្បាស់លាស់តាមក្បួន snake_case និងចៀសវាងប្រើពាក្យគន្លឹះរបស់ Python ដូចជា if, for, class មកធ្វើជាឈ្មោះអថេរ។

Python Programming 03. Python Data Types & Type Casting

03. Python Data Types & Type Casting (Detail)

1. Definition (និយមន័យ):

Data Type (ប្រភេទទិន្នន័យ) គឺជាការបែងចែកប្រភេទ ឬលក្ខណៈសម្គាល់របស់ទិន្នន័យនីមួយៗ (ដូចជា អក្សរ លេខគត់ លេខក្បៀស ឬតម្លៃពិត/មិនពិត) ដើម្បីឱ្យ Python ស្គាល់ និងអាចយកទិន្នន័យទាំងនោះទៅគណនា ឬប្រើប្រាស់បានត្រឹមត្រូវ។

2. មូលដ្ឋានគ្រឹះ Data Type:

  • str (String)៖ ជាប្រភេទទិន្នន័យអត្ថបទ សរសេរក្នុង "..." ឬ '...' (ឧ. "Hello")។
  • int (Integer)៖ ជាប្រភេទទិន្នន័យលេខចំនួនគត់ ទាំងវិជ្ជមាន និងអវិជ្ជមាន គ្មានក្បៀស (ឧ. 100, -25)។
  • float (Floating Point)៖ ជាប្រភេទទិន្នន័យលេខទសភាគ ដែលមានចំណុចក្បៀស (ឧ. 19.99, 3.14)។
  • bool (Boolean)៖ ជាប្រភេទទិន្នន័យតក្កវិទ្យា មានតែ ២ គត់គឺ True (ពិត) និង False (មិនពិត)។
  • NoneType (None)៖ ជាប្រភេទទិន្នន័យដែលតំណាងឱ្យភាពទទេ ឬគ្មានតម្លៃអ្វីទាំងអស់ (data = None)។
  • type() (ឆែកប្រភេទទិន្នន័យ)៖ ប្រើសម្រាប់ពិនិត្យមើលប្រភេទរបស់ទិន្នន័យ (ឧ. type(10))។
  • int(), float(), str() (Type Casting)៖ ប្រើសម្រាប់បម្លែងប្រភេទទិន្នន័យពីមួយទៅមួយ។

3. Syntax (ទម្រង់កូដ):

text = "Python"          # str
qty = 5                  # int
price = 12.50            # float
is_active = True         # bool

# Type Casting: បម្លែងអក្សរ "100" ទៅជា int ដើម្បីបូកលេខ
result = int("100") + qty
print(type(price), type(is_active), "| Result:", result)

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python datatypes.py
<class 'float'> <class 'bool'> | Result: 105
5. Summary (សង្ខេបមេរៀន)៖ Data Type គឺជាប្រភេទនៃទិន្នន័យ ដែលវាស្របទៅតាមទិន្នន័យរបស់យើងជាក់ស្តែង។ ប្រើ type() ដើម្បីឆែកប្រភេទទិន្នន័យ ហើយត្រូវចាំថា Python មិនអនុញ្ញាតឱ្យយក str បូកជាមួយ int ផ្ទាល់ទេ ត្រូវប្រើ int() ឬ float() បម្លែងជាមុនសិន។

Python Programming 04. User Input & String Formatting

04. User Input & String Formatting (f-strings)

1. Definition (និយមន័យ):

input() ប្រើសម្រាប់ទទួលទិន្នន័យពីអ្នកប្រើប្រាស់តាម Keyboard ហើយ f-string (f"...") ប្រើសម្រាប់បញ្ចូលអថេរទៅក្នុងអត្ថបទយ៉ាងខ្លី និងស្អាតបំផុត។

2. មុខងារសំខាន់ៗ:

  • input() (ទទួលទិន្នន័យ)៖ ផ្តល់តម្លៃជា str ជានិច្ច ត្រូវបម្លែងជា int() បើចង់គណនាលេខ។
  • f"{variable}" (f-string)៖ ដាក់អក្សរ f នៅខាងមុខធ្មេញកណ្តុរ ដើម្បីបង្ហាញតម្លៃអថេរក្នុង { }។
  • .strip() (សម្អាតដកឃ្លា)៖ លុបចន្លោះដកឃ្លាដែលលើសនៅខាងដើម និងខាងចុងអត្ថបទ។
  • .upper() & .lower() ៖ បម្លែងអត្ថបទទៅជាអក្សរធំទាំងអស់ ឬអក្សរតូចទាំងអស់។

3. Syntax (ទម្រង់កូដ):

name = input("បញ្ចូលឈ្មោះរបស់អ្នក៖ ").strip()
birth_year = int(input("បញ្ចូលឆ្នាំកំណើត៖ "))
age = 2026 - birth_year
print(f"សួស្តី {name}! នៅឆ្នាំ ២០២៦ អ្នកមានអាយុ {age} ឆ្នាំហើយ។")

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python age_calc.py
បញ្ចូលឈ្មោះរបស់អ្នក៖ ដារ៉ា | បញ្ចូលឆ្នាំកំណើត៖ 2005
សួស្តី ដារ៉ា! នៅឆ្នាំ ២០២៦ អ្នកមានអាយុ 21 ឆ្នាំហើយ។
5. Summary (សង្ខេបមេរៀន)៖ ត្រូវចាំថា input() ផ្តល់តម្លៃជា str ជានិច្ច ហើយប្រើ f"..." ដើម្បីភ្ជាប់អថេរជាមួយអត្ថបទ។

05. Arithmetic & Assignment Operators

1. Definition (និយមន័យ):

Arithmetic Operators ប្រើសម្រាប់ធ្វើប្រមាណវិធីគណិតវិទ្យា រីឯ Assignment Operators ប្រើសម្រាប់ផ្តល់ និងបូកបន្ថែមតម្លៃឱ្យអថេរដោយសរសេរកាត់ខ្លី។

2. មុខងារសំខាន់ៗ:

  • +, -, *, / ៖ បូក ដក គុណ និងចែកយកទសភាគ (ឧ. 10 / 3 = 3.333...)។
  • // (Floor Division)៖ ចែកយកតែចំនួនគត់ កាត់ក្បៀសចោល (ឧ. 10 // 3 = 3)។
  • % (Modulus)៖ ចែកយកសំណល់ (ឧ. 10 % 3 = 1)។
  • ** (Exponentiation)៖ លើកជាស្វ័យគុណ (ឧ. 2 ** 3 = 8)។
  • +=, -=, *=, /= (Assignment)៖ សរសេរកាត់ (ឧ. x += 5 ស្មើនឹង x = x + 5)។

3. Syntax (ទម្រង់កូដ):

a, b = 10, 3
print("ចែកគត់ (//)៖", a // b, "| សំណល់ (%)៖", a % b, "| ស្វ័យគុណ (**)៖", a ** b)

score = 50
score += 15   # បូកបន្ថែម 15 ចូលក្នុង score
print("ពិន្ទុបន្ទាប់ពី += 15៖", score)

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python arithmetic.py
ចែកគត់ (//)៖ 3 | សំណល់ (%)៖ 1 | ស្វ័យគុណ (**)៖ 1000
ពិន្ទុបន្ទាប់ពី += 15៖ 65
5. Summary (សង្ខេបមេរៀន)៖ សញ្ញា / តែងតែផ្តល់លទ្ធផលជា float ជានិច្ច ទោះបីចែកដាច់ក៏ដោយ (ឧ. 10 / 2 = 5.0)។

Python Programming 06. Comparison & Logical Operators

06. Comparison & Logical Operators

1. Definition (និយមន័យ):

Comparison Operators ប្រើសម្រាប់ប្រៀបធៀបតម្លៃពីរ រីឯ Logical Operators ប្រើសម្រាប់ភ្ជាប់លក្ខខណ្ឌច្រើនចូលគ្នា ដោយលទ្ធផលចេញជា True ឬ False ជានិច្ច។

2. មុខងារសំខាន់ៗ:

  • == & != (ស្មើ & មិនស្មើ)៖ ពិនិត្យថាតើតម្លៃទាំងពីរស្មើគ្នា ឬខុសគ្នាឬអត់។
  • >, <, >=, <= (ប្រៀបធៀបទំហំ)៖ ធំជាង តូចជាង ធំជាងឬស្មើ និងតូចជាងឬស្មើ។
  • and (និង)៖ ផ្តល់ True លុះត្រាតែលក្ខខណ្ឌទាំងសងខាងពិតទាំងពីរ។
  • or (ឬ)៖ ផ្តល់ True ប្រសិនបើមានលក្ខខណ្ឌយ៉ាងតិចមួយពិត។
  • not (មិនមែន)៖ បញ្ច្រាសលទ្ធផលពី True ទៅ False និងច្រាសមកវិញ។

3. Syntax (ទម្រង់កូដ):

x, y = 10, 20
print("x == y:", x == y, "| x != y:", x != y, "| x < y:", x < y)

age = 20; has_id = True
print("អាចបើកបរបាន (and):", age >= 18 and has_id)

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python comparison.py
x == y: False | x != y: True | x < y: True
អាចបើកបរបាន (and): True
5. Summary (សង្ខេបមេរៀន)៖ Comparison និង Logical Operators គឺជាគ្រឹះសម្រាប់សរសេរលក្ខខណ្ឌក្នុង if-else និង while loop។

Python Programming 07. Conditional Statements

07. Conditional Statements (if-else, Shorthand & match-case)

1. Definition (និយមន័យ):

Conditional Statements ប្រើសម្រាប់ឱ្យកម្មវិធីសម្រេចចិត្តដំណើរការកូដតាមលក្ខខណ្ឌពិត (True) ឬមិនពិត (False)។

2. មុខងារសំខាន់ៗ:

  • if (ប្រសិនបើ)៖ ពិនិត្យលក្ខខណ្ឌដំបូង បើពិតនឹងដំណើរការកូដខាងក្នុង។
  • elif (ផ្ទុយទៅវិញ ប្រសិនបើ)៖ ពិនិត្យលក្ខខណ្ឌបន្ទាប់ នៅពេលលក្ខខណ្ឌខាងលើមិនពិត។
  • else (ក្រៅពីនេះ)៖ ដំណើរការនៅពេលគ្រប់លក្ខខណ្ឌខាងលើមិនពិតទាំងអស់។
  • Ternary Operator (Shorthand If-Else)៖ សរសេរ if-else បង្រួមក្នុង ១ បន្ទាត់ (val_true if condition else val_false)។
  • match-case (Python 3.10+)៖ ផ្ទៀងផ្ទាត់តម្លៃតាមករណីនីមួយៗ ជំនួសការសរសេរ elif ច្រើនជាន់។

3. Syntax (ទម្រង់កូដ):

# 1. ការប្រើប្រាស់ if - elif - else ធម្មតា
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"

# 2. ការសរសេរ if-else ខ្លី (Shorthand / Ternary)
status_exam = "ជាប់" if score >= 50 else "ធ្លាក់"

# 3. ការប្រើប្រាស់ match-case (ផ្នែកខាងក្រោម)
day = 6
match day:
    case 1 | 2 | 3 | 4 | 5:
        day_type = "ថ្ងៃធ្វើការ (Weekday)"
    case 6 | 7:
        day_type = "ថ្ងៃចុងសប្តាហ៍ (Weekend)"
    case _:
        day_type = "លេខថ្ងៃមិនត្រឹមត្រូវ"

print(f"និទ្ទេស៖ {grade} ({status_exam}) | ប្រភេទថ្ងៃ៖ {day_type}")

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python conditions.py
និទ្ទេស៖ B (ជាប់) | ប្រភេទថ្ងៃ៖ ថ្ងៃចុងសប្តាហ៍ (Weekend)
5. Summary (សង្ខេបមេរៀន)៖ ប្រើ if-elif-else សម្រាប់លក្ខខណ្ឌទូទៅ ប្រើ Shorthand ពេលចង់កំណត់តម្លៃរហ័សក្នុង ១ បន្ទាត់ និងប្រើ match-case ពេលពិនិត្យតម្លៃ Option ច្រើនស្អាតនិងងាយអាន (សញ្ញា | មានន័យថា "ឬ")។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 9
Python Programming 08. Loops in Python

08. Loops in Python (for, while, break, continue)

1. Definition (និយមន័យ):

Loop គឺជាការបញ្ជាឱ្យកូដដំណើរការដដែលៗដោយស្វ័យប្រវត្តិ រហូតដល់ចប់ចំនួនជុំដែលបានកំណត់ ឬលក្ខខណ្ឌលែងពិត។

2. មុខងារសំខាន់ៗ:

  • while loop ៖ រត់ដដែលៗដរាបណាលក្ខខណ្ឌនៅតែពិត (True)។
  • for loop ៖ រត់តាមចំនួនជុំ range(start, stop) ឬទាញទិន្នន័យពី List/Tuple/Set/Dict។
  • break ៖ បញ្ឈប់ និងផ្តាច់ចេញពី Loop ទាំងស្រុងមុនពេលចប់ជុំ។
  • continue ៖ រំលងកូដខាងក្រោមក្នុងជុំបច្ចុប្បន្ន ហើយលោតទៅជុំបន្ទាប់។

3. Syntax (ទម្រង់កូដ):

# 1. ឧទាហរណ៍ for loop (ប្រើ continue រំលងលេខ 2)
for i in range(1, 4):
    if i == 2: continue
    print(f"For ជុំទី {i}")

# 2. ឧទាហរណ៍ while loop (ប្រើ break ឈប់ពេលដល់លេខ 3)
count = 1
while count <= 5:
    if count == 3: break
    print(f"While ជុំទី {count}")
    count += 1

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python loops.py
For ជុំទី 1 | For ជុំទី 3
While ជុំទី 1 | While ជុំទី 2
5. Summary (សង្ខេបមេរៀន)៖ ប្រើ for ពេលដឹងចំនួនជុំច្បាស់លាស់ ប្រើ while ពេលរង់ចាំលក្ខខណ្ឌ និងប្រើ break/continue ដើម្បីគ្រប់គ្រងការរត់របស់ Loop។

Python Programming 09. Python Lists & Loop

09. Python Lists & Loop over Lists

1. Definition (និយមន័យ):

List គឺជាបញ្ជីផ្ទុកទិន្នន័យច្រើនក្នុងអថេរតែមួយ ប្រើសញ្ញា [ ] មានលំដាប់ (Ordered) អាចកែប្រែបាន (Mutable) និងអាចប្រើ Loop ដើម្បីទាញទិន្នន័យទាំងអស់មកប្រើប្រាស់។

2. មុខងារសំខាន់ៗ (Methods & Loop over List):

  • .append(item) ៖ បន្ថែមធាតុថ្មីទៅចុងបញ្ចប់នៃ List។
  • .insert(index, item) ៖ បញ្ចូលធាតុថ្មីទៅតាមទីតាំង Index ដែលកំណត់។
  • .remove(item) ៖ លុបធាតុចេញពី List ដោយបញ្ជាក់ឈ្មោះតម្លៃ។
  • .pop(index) ៖ លុបធាតុចុងក្រោយ ឬលុបតាមលេខ Index។
  • .sort() & .reverse() ៖ តម្រៀបទិន្នន័យតាមលំដាប់ និងត្រឡប់បញ្ច្រាស List។
  • len(list) ៖ រាប់ចំនួនធាតុសរុបដែលមាននៅក្នុង List។
  • For Loop ធម្មតា៖ for item in my_list: ទាញតម្លៃម្តងមួយៗចេញពី List។
  • Loop with enumerate()៖ ទាញយកទាំងលេខរៀង (Index) និងតម្លៃ (Value) ព្រមគ្នា។

3. Syntax (ទម្រង់កូដ):

courses = ["HTML", "CSS", "JS"]
courses.append("Python")     # បន្ថែមទៅចុង
courses.insert(1, "Tailwind")  # បញ្ចូលត្រង់ Index ទី 1
courses.remove("JS")         # លុប "JS" ចេញ

# របៀបប្រើ Loop ទាញទាំង Index និង Value ពី List
for idx, item in enumerate(courses, start=1):
    print(f"{idx}. {item}")

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python list_loop.py
1. HTML | 2. Tailwind | 3. CSS | 4. Python
5. Summary (សង្ខេបមេរៀន)៖ List ប្រើ [ ] សម្រាប់ផ្ទុកបញ្ជីទិន្នន័យ មាន Methods ជាច្រើនសម្រាប់គ្រប់គ្រង និងប្រើ enumerate() ពេលចង់បានទាំងលេខរៀង និងតម្លៃក្នុង Loop។

Python Programming 10. Tuples, Sets & Loop

10. Tuples, Sets & Loop over Tuples/Sets

1. Definition (និយមន័យ):

Tuple (()) គឺជាបញ្ជីផ្ទុកទិន្នន័យច្រើនក្នុងអថេរតែមួយ ដែលមិនអាចកែប្រែតម្លៃបាន។ រីឯ Set ({}) គឺជាបញ្ជីផ្ទុកទិន្នន័យច្រើនក្នុងអថេរតែមួយ ដែលគ្មានលំដាប់ និងមិនឱ្យមានតម្លៃស្ទួន។ ទាំងពីរនេះអាចប្រើជាមួយ for loop បានដូច List ដែរ។

2. មុខងារសំខាន់ៗ (Methods & Loop over Tuple/Set):

  • .count() & .index() (Tuple)៖ រាប់ចំនួនតម្លៃដូចគ្នា និងស្វែងរកទីតាំង Index ក្នុង Tuple។
  • .add(item) (Set)៖ បន្ថែមធាតុថ្មីចូលទៅក្នុង Set។
  • .remove(item) (Set)៖ លុបធាតុចេញពី Set។
  • .union() & .intersection() (Set)៖ បូកបញ្ចូលគ្នា ឬរកចំណុចរួមរវាង Set ពីរ។
  • Loop over Tuple៖ for val in my_tuple: រត់តាមលំដាប់ពីដើមដល់ចប់ និងអាច Unpack តម្លៃបាន។
  • Loop over Set៖ for val in my_set: រត់ទាញយកតែធាតុដែលមិនស្ទួន (Unique) ប៉ុន្តែលំដាប់មិនទៀងទាត់ឡើយ។

3. Syntax (ទម្រង់កូដ):

# 1. Loop ជាមួយ Tuple
roles = ("Admin", "Teacher", "Student")
for r in roles:
    print("Role:", r)

# 2. Loop ជាមួយ Set (លុបតម្លៃស្ទួនស្វ័យប្រវត្តិ)
tags = {"python", "web", "python"}
tags.add("api")
for t in tags:
    print("Tag:", t)

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python tuple_set_loop.py

Python Programming 11. Python Dictionaries & Loop

11. Python Dictionaries & Loop over Dictionaries

1. Definition (និយមន័យ):

Dictionary ({}) គឺជាបញ្ជីផ្ទុកទិន្នន័យច្រើនក្នុងអថេរតែមួយ ដោយវាគិតជាគូៗ Key: Value។ ការប្រើ Loop ជាមួយ Dictionary មាន ៣ របៀបសំខាន់ៗ អាស្រ័យថាតើអ្នកចង់ទាញ Key, Value ឬទាំងពីរ។

2. របៀប Loop over Dictionary ទាំង ៣ & Methods:

  • for k in my_dict.keys(): ៖ ទាញយកតែឈ្មោះ Key ទាំងអស់។
  • for v in my_dict.values(): ៖ ទាញយកតែតម្លៃ Value ទាំងអស់។
  • for k, v in my_dict.items(): ៖ ទាញយកទាំង Key និង Value ព្រមគ្នា (ពេញនិយមបំផុត)។
  • .get("key") ៖ ទាញយកតម្លៃតាមឈ្មោះ Key ដោយសុវត្ថិភាព (មិន Error ពេលរកមិនឃើញ)។
  • .pop("key") ៖ លុបទិន្នន័យចេញពី Dictionary ដោយបញ្ជាក់ឈ្មោះ Key។

3. Syntax (ទម្រង់កូដ):

student = {"name": "ដារ៉ា", "course": "Python", "score": 95}

# ទាញទាំង Key និង Value ដោយប្រើ .items()
for key, value in student.items():
    print(f"{key} ➔ {value}")

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python dict_loop.py
name ➔ ដារ៉ា
course ➔ Python
score ➔ 95
5. Summary (សង្ខេបមេរៀន)៖ Dictionary ({}) ប្រើសម្រាប់ផ្ទុកទិន្នន័យជាគូៗ Key: Value។ ប្រើ .keys() យក Key, ប្រើ .values() យកតម្លៃ និងប្រើ .items() យកទាំងគូក្នុង Loop។

12. Functions, Parameters & Return Values

1. Definition (និយមន័យ):

Function (អនុគមន៍) គឺជាការបែងចែកកូដជាប្លុកផ្សេងៗគ្នា សម្រាប់បំពេញការងារជាក់លាក់ និងអាចហៅប្រើឡើងវិញបានច្រើនដង។

2. មុខងារសំខាន់ៗ:

  • def function_name(): ៖ ពាក្យគន្លឹះ def ប្រើសម្រាប់បង្កើត ឬប្រកាសអនុគមន៍ថ្មី។
  • Function Call (ការហៅប្រើ)៖ សរសេរឈ្មោះអនុគមន៍ដោយមានវង់ក្រចក function_name() ដើម្បីឱ្យកូដខាងក្នុងដំណើរការ។
  • Parameters (ប៉ារ៉ាម៉ែត្រ)៖ ជាអថេរដែលកំណត់នៅក្នុងវង់ក្រចក () ពេលបង្កើត Function សម្រាប់រង់ចាំទទួលតម្លៃ ពេលគេផ្តល់ឱ្យកំឡុងពេលហៅ function។
  • Arguments (អាគុយម៉ង់)៖ ជាតម្លៃជាក់ស្តែងដែលបញ្ជូនចូលទៅឱ្យ Function នៅពេលហៅវាមកប្រើ។
  • return (បញ្ជូនតម្លៃចេញក្រៅ)៖ ប្រើសម្រាប់បញ្ជូនតម្លៃចេញពី Function ត្រឡប់ទៅកន្លែងដែលបានហៅវា ហើយឈប់ឱ្យកូដបន្តទៅខាងក្រោមទៀត។

def calculate_total(price, qty, discount=0):

Terminal: python functions.py

13. *args, **kwargs & Lambda Functions

1. Definition (និយមន័យ):

អ្នកអាចបង្កើតអនុគមន៍ទទួលតម្លៃចូលមិនកំណត់ចំនួនដោយប្រើ *args និង **kwargs ព្រមទាំងសរសេរអនុគមន៍ខ្លី ១ បន្ទាត់ដោយប្រើ lambda។

2. មុខងារសំខាន់ៗ:

  • *args ៖ ទទួលតម្លៃចូលច្រើនមិនកំណត់ទុកជា Tuple (())។
  • **kwargs ៖ ទទួលតម្លៃជាគូ key=value មិនកំណត់ចំនួន ទុកជា Dictionary ({})។
  • lambda ៖ អនុគមន៍គ្មានឈ្មោះ (Anonymous Function) សរសេរក្នុង ១ បន្ទាត់ (lambda args: expression)។

3. Syntax (ទម្រង់កូដ):

# 1. *args (ទទួលតម្លៃច្រើនជា Tuple)
def sum_all(*numbers):
    return sum(numbers)

# 2. **kwargs (ទទួលតម្លៃជា Dictionary)
def user_info(**info):
    return info["name"]

# 3. lambda (អនុគមន៍ខ្លី ១ បន្ទាត់)
square = lambda x: x ** 2

print("Sum:", sum_all(10, 20, 30), "| User:", user_info(name="ដារ៉ា"), "| Square:", square(5))

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python adv_func.py
Sum: 60 | User: ដារ៉ា | Square: 25
5. Summary (សង្ខេបមេរៀន)៖ ប្រើ *args និង **kwargs ពេលមិនកំណត់ចំនួន Parameters និងប្រើ lambda សម្រាប់គណនាតម្លៃខ្លីៗក្នុង ១ បន្ទាត់។

Python Programming 15. Exception Handling

15. Exception Handling (try, except, finally)

1. Definition (និយមន័យ):

Exception Handling គឺជាបច្ចេកទេសចាប់ និងដោះស្រាយកំហុស (Runtime Errors) ដើម្បីការពារកុំឱ្យកម្មវិធីគាំង (Crash) ពេលអ្នកប្រើប្រាស់បញ្ចូលទិន្នន័យខុស។

2. មុខងារសំខាន់ៗ:

  • try: (ពាក្យគន្លឹះ)៖ ដាក់កូដដែលសង្ស័យថាអាចនឹងមាន Error កើតឡើងដើម្បីសាកល្បងដំណើរការ។
  • except: (ពាក្យគន្លឹះ)៖ ចាប់យក Error មកដោះស្រាយដោយសុវត្ថិភាព ដើម្បីកុំឱ្យកម្មវិធីគាំង (Crash)។
  • finally: (ពាក្យគន្លឹះ)៖ ដំណើរការជានិច្ច មិនថាមាន Error ឬអត់ឡើយ។

ប្រភេទ Error សំខាន់ៗ (Built-in Exceptions):

  • ValueError (ប្រភេទ Error តម្លៃខុស)៖ កើតឡើងពេលបំប្លែងទិន្នន័យខុសតម្លៃ (ឧ. int("abc"))។
  • ZeroDivisionError (ប្រភេទ Error ចែកនឹងសូន្យ)៖ កើតឡើងពេលយកលេខទៅចែកនឹង 0 (ឧ. 10 / 0)។
  • TypeError (ប្រភេទ Error ខុសប្រភេទទិន្នន័យ)៖ កើតឡើងពេលប្រើប្រភេទទិន្នន័យខុសគ្នា (ឧ. "5" + 2)។
  • FileNotFoundError (ប្រភេទ Error រកឯកសារមិនឃើញ)៖ កើតឡើងពេលបើកឯកសារដែលគ្មាន។
  • Exception (ប្រភេទ Error ទូទៅ)៖ ចាប់យករាល់ Error ទាំងអស់ ប្រសិនបើមិនដឹងឈ្មោះ Error ច្បាស់។

3. Syntax (ទម្រង់កូដ):

try:
    num = int("abc")
except ValueError:
    print("កំហុស៖ សូមបញ្ចូលតែលេខប៉ុណ្ណោះ!")
finally:
    print("បញ្ចប់ការត្រួតពិនិត្យ។")

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python error_handle.py
កំហុស៖ សូមបញ្ចូលតែលេខប៉ុណ្ណោះ!
បញ្ចប់ការត្រួតពិនិត្យ។
5. Summary (សង្ខេបមេរៀន)៖ ត្រូវប្រើ try...except ជានិច្ចនៅពេលទទួលទិន្នន័យពី User ឬបើកឯកសារ។

Python Programming 16. File Handling (Read & Write Files)

16. File Handling (Read & Write Files)

1. Definition (និយមន័យ):

File Handling គឺជាការអាន និងសរសេរទិន្នន័យចូលទៅក្នុងឯកសារនៅលើ Hard Disk ដោយប្រើ open() ជាមួយពាក្យគន្លឹះ with។

2. មុខងារសំខាន់ៗ:

  • open(file, mode) (អនុគមន៍)៖ ប្រើសម្រាប់បើកឯកសារដោយកំណត់ទីតាំង និងប្រភេទនៃការប្រើប្រាស់ (Mode)។
  • with ... as f: (ពាក្យគន្លឹះ)៖ បិទឯកសារដោយស្វ័យប្រវត្តិក្រោយប្រើរួច ដើម្បីការពារការខូចទិន្នន័យ។
  • .read() / .write() (Methods)៖ ប្រើសម្រាប់អានទិន្នន័យចេញ ឬសរសេរទិន្នន័យចូលក្នុងឯកសារ។

ប្រភេទ File Modes ទាំង ៧ ក្នុង Python:

  • "r" (Read - អាន)៖ បើកឯកសារដើម្បីអានប៉ុណ្ណោះ (ជាតម្លៃដើម Default)។
  • "w" (Write - សរសេរថ្មី)៖ បង្កើតឯកសារថ្មី ឬលុបទិន្នន័យចាស់ចោលរួចសរសេរជាន់ពីលើ។
  • "a" (Append - សរសេរបន្ថែម)៖ សរសេរទិន្នន័យបន្ថែមពីខាងចុង ដោយរក្សាទិន្នន័យចាស់ទុកដដែល។
  • "x" (Exclusive Creation - បង្កើតថ្មីសុទ្ធ)៖ បង្កើតឯកសារថ្មី តែនឹង Error ប្រសិនបើមានឯកសារនោះរួចហើយ។
  • "t" (Text Mode - ឯកសារអក្សរ)៖ បើកជាប្រភេទឯកសារអក្សរទូទៅ (ជាតម្លៃដើម Default)។
  • "b" (Binary Mode - ឯកសារទិន្នន័យ)៖ ប្រើសម្រាប់រូបភាព វីដេអូ ឬ PDF (ឧ. "rb", "wb")។
  • "+" (Read & Write - អាន និងសរសេរ)៖ ផ្សំដើម្បីអានផង សរសេរផងក្នុងពេលតែមួយ (ឧ. "r+", "w+")។

3. Syntax (ទម្រង់កូដ):

with open("note.txt", "w", encoding="utf-8") as f: f.write("សួស្តី Python\n") # "w" សរសេរថ្មី

with open("note.txt", "rb") as f: print(f.read(6)) # "rb" អានជា Binary (Bytes)

b'\xe1\x9e\x9f\xe1\x9e\xbd'

Python Programming 17. OOP Part 1: Classes & Objects

17. OOP Part 1: Classes, Objects & __init__

1. Definition (និយមន័យ):

OOP (Object-Oriented Programming) គឺជារបៀបសរសេរកម្មវិធីដោយចងក្រងទិន្នន័យ (Attributes) និងមុខងារ (Methods) ចូលគ្នាជា Object តាមរយៈពុម្ពគំរូដើម Class។

2. មុខងារ និងធាតុផ្សំសំខាន់ៗ:

  • class ClassName: (ពុម្ពគំរូ)៖ សម្រាប់បង្កើតពុម្ពគំរូ (សរសេរអក្សរធំដើមពាក្យ ឬ PascalCase)។
  • obj = ClassName() (Object / Instance)៖ វត្ថុពិតប្រាកដដែលបង្កើតចេញពី Class។
  • __init__(self, ...) (Constructor)៖ អនុគមន៍ពិសេសដែលដំណើរការស្វ័យប្រវត្តិពេលបង្កើត Object ថ្មី។
  • self (Self Parameter)៖ តំណាងឱ្យ Object បច្ចុប្បន្ន ប្រើសម្រាប់ទាញយកទិន្នន័យ និងមុខងារខាងក្នុង Class។

សមាសធាតុខាងក្នុង Class (Class Members):

  • Attributes (លក្ខណៈសម្បត្តិ / ទិន្នន័យ)៖ អថេរដែលផ្ទុកព័ត៌មានរបស់ Object (ឧ. self.name, self.age)។
  • Methods (មុខងារ / សកម្មភាព)៖ អនុគមន៍ដែលសរសេរនៅក្នុង Class ដើម្បីឱ្យ Object ធ្វើសកម្មភាពអ្វីមួយ (ឧ. def say(self):)។

3. Syntax (ទម្រង់កូដ):

class Student:
    def __init__(self, name):
        self.name = name  # Attribute (លក្ខណៈសម្បត្តិ)

    def say(self):        # Method (មុខងារ)
        return f"សួស្តី {self.name}"

stu1 = Student("សុខា")    # បង្កើត Object
print(stu1.say())

Python Programming 18. OOP Part 2: Inheritance & Polymorphism

18. OOP Part 2: Inheritance & Polymorphism

1. Definition (និយមន័យ):

Inheritance (ការស្នងមរតក) អនុញ្ញាតឱ្យ Child Class ទទួលយក Attributes និង Methods ពី Parent Class មកប្រើដោយមិនបាច់សរសេរឡើងវិញ។ រីឯ Polymorphism (ពហុទម្រង់) គឺជាសមត្ថភាពដែល Method ឈ្មោះដូចគ្នា អាចដំណើរការខុសគ្នាទៅតាមប្រភេទ Class នីមួយៗ។

2. មុខងារ និងគោលការណ៍សំខាន់ៗ:

  • class Child(Parent): (Inheritance)៖ បង្កើត Class កូនដែលទទួលមរតកពី Class មេ (Parent)។
  • super() (Super Function)៖ ហៅប្រើ __init__() ឬ Method របស់ Parent Class នៅខាងក្នុង Child Class។
  • Method Overriding (Polymorphism)៖ សរសេរកែប្រែ Method ដែលមានឈ្មោះដូច Parent នៅក្នុង Child Class ដើម្បីឱ្យវាធ្វើការខុសគ្នា។

តួនាទីសំខាន់ៗក្នុង Inheritance:

  • Parent Class (Base / Super Class)៖ ជា Class មេដែលផ្ទុកលក្ខណៈសម្បត្តិ និងមុខងាររួម។
  • Child Class (Derived / Sub Class)៖ ជា Class កូនដែលស្នងមរតកពី Class មេ ហើយអាចបន្ថែមមុខងារផ្ទាល់ខ្លួនបាន។

3. Syntax (ទម្រង់កូដ):

class User:                                  # Parent Class
    def role(self): return "General User"

class Admin(User):                           # Child Class (Inheritance)
    def role(self): return "System Admin"  # Method Overriding (Polymorphism)

for account in [User(), Admin()]:
    print(account.role())

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python inherit.py
General User
System Admin
5. Summary (សង្ខេបមេរៀន)៖ Inheritance ជួយកាត់បន្ថយការសរសេរកូដស្ទួន រីឯ Polymorphism ជួយឱ្យកូដមានភាពបត់បែនតាមរយៈ Method Overriding។

Python Programming 19. OOP Part 3: Encapsulation & Magic Methods

19. OOP Part 3: Encapsulation & Magic Methods

1. Definition (និយមន័យ):

Encapsulation (ការវេចខ្ចប់ និងការពារទិន្នន័យ) គឺជាការលាក់ទិន្នន័យសំខាន់ៗក្នុង Class កុំឱ្យកែប្រែផ្ទាល់ពីខាងក្រៅដោយប្រើ __។ រីឯ Magic Methods (Dunder Methods) គឺជាអនុគមន៍ពិសេសដែលមានសញ្ញា __ នៅមុខ និងក្រោយ សម្រាប់កំណត់ឥរិយាបថពិសេសឱ្យ Object។

2. មុខងារ និងសមាសធាតុសំខាន់ៗ:

  • Getter & Setter Methods៖ អនុគមន៍សម្រាប់ទាញមើល (Get) ឬកែប្រែ (Set) តម្លៃរបស់ Private Attribute ដោយមានលក្ខខណ្ឌត្រួតពិនិត្យត្រឹមត្រូវ។
  • __str__(self) (Magic Method)៖ កំណត់អត្ថបទបង្ហាញពេលប្រើ print(object) ជំនួសឱ្យលេខកូដ Memory។
  • __len__(self) (Magic Method)៖ កំណត់តម្លៃប្រវែង ឬចំនួនពេលប្រើអនុគមន៍ len(object)។

កម្រិតការពារទិន្នន័យក្នុង Python (Access Modifiers):

  • self.var (Public)៖ អាចហៅប្រើ និងកែប្រែបានដោយសេរីពីគ្រប់ទីកន្លែង។
  • self._var (Protected)៖ ប្រើបានតែក្នុង Class ខ្លួនឯង និង Child Class ប៉ុណ្ណោះ (ជាកិច្ចព្រមព្រៀង)។
  • self.__var (Private)៖ ការពារតឹងរ៉ឹង មិនឱ្យហៅប្រើ ឬកែប្រែផ្ទាល់ពីខាងក្រៅ Class ឡើយ។

3. Syntax (ទម្រង់កូដ):

class Account:
    def __init__(self, bal):
        self.__bal = bal                             # Private Attribute (Encapsulation)

    def get_bal(self): return self.__bal             # Getter Method
    def __str__(self): return f"Balance: ${self.__bal}" # Magic Method

acc = Account(500)
print(acc)

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python encaps.py
Balance: $500
5. Summary (សង្ខេបមេរៀន)៖ ប្រើ __ ជាមួយ Getter/Setter ដើម្បីការពារសុវត្ថិភាពទិន្នន័យ និងប្រើ Magic Methods ដើម្បីគ្រប់គ្រងឥរិយាបថ Object។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 21
Python Programming 20. Decorators & Generators

20. Decorators & Generators (Advanced Python)

1. Definition (និយមន័យ):

Decorator (@decorator) គឺជាបច្ចេកទេសបន្ថែមមុខងារពិសេសឱ្យអនុគមន៍ដទៃដោយមិនបាច់កែកូដដើម។ រីឯ Generator គឺជាអនុគមន៍ដែលប្រើ yield ដើម្បីបង្កើត និងបញ្ជូនទិន្នន័យម្តងមួយៗ ជួយសន្សំសំចៃ Memory។

2. មុខងារ និងពាក្យគន្លឹះសំខាន់ៗ:

  • @decorator_name (Decorator Syntax)៖ ដាក់ពីលើអនុគមន៍ដើម្បីរុំព័ទ្ធ និងបន្ថែមមុខងារមុន ឬក្រោយពេលអនុគមន៍ដើមដំណើរការ។
  • yield (Generator Keyword)៖ ផ្អាកអនុគមន៍បណ្តោះអាសន្ន និងបញ្ជូនតម្លៃម្តងមួយៗ (ខុសពី return ដែលបញ្ចប់អនុគមន៍ភ្លាម)។
  • next(gen) (Built-in Function)៖ ប្រើសម្រាប់ទាញយកតម្លៃបន្ទាប់ម្តងមួយៗចេញពី Generator។

អត្ថប្រយោជន៍ជាក់ស្តែងក្នុងការអនុវត្ត:

  • Decorators៖ និយមប្រើសម្រាប់ពិនិត្យសិទ្ធិអ្នកប្រើប្រាស់ (Authentication), កត់ត្រាទិន្នន័យ (Logging) និងវាស់ល្បឿនកូដ។
  • Generators៖ និយមប្រើសម្រាប់ដំណើរការទិន្នន័យធំៗ (Big Data / Large Files) ដោយមិនធ្វើឱ្យពេញ RAM។

3. Syntax (ទម្រង់កូដ):

def decorator(f):                                # បង្កើត Decorator
    def wrap(): print("Start"); f()
    return wrap

@decorator
def say(): print("Python")

def count_gen():                                 # បង្កើត Generator
    yield 1; yield 2

say()
print(list(count_gen()))

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python dec_gen.py
Start
Python
[1, 2]
5. Summary (សង្ខេបមេរៀន)៖ Decorators ជួយបន្ថែមមុខងារលើអនុគមន៍ដោយមិនកែកូដដើម រីឯ Generators (yield) ជួយសន្សំសំចៃ Memory ពេលដំណើរការទិន្នន័យច្រើន។

Python Programming 21. Working with APIs & Virtual Env

21. Working with APIs (requests) & Virtual Env

1. Definition (និយមន័យ):

Virtual Environment (venv) គឺជាបរិស្ថានដាច់ដោយឡែកសម្រាប់គ្រប់គ្រង Libraries នៃគម្រោងនីមួយៗកុំឱ្យជាន់គ្នា។ រីឯ API (requests) គឺជាការភ្ជាប់ទំនាក់ទំនងដើម្បីទាញ ឬបញ្ជូនទិន្នន័យរវាងកម្មវិធី និង Server។

2. មុខងារ និងពាក្យបញ្ជាសំខាន់ៗ:

  • python -m venv venv (បង្កើត venv)៖ បង្កើត Folder បរិស្ថានដាច់ដោយឡែកសម្រាប់គម្រោង។
  • venv\Scripts\activate (បើកដំណើរការ)៖ បើកប្រើ venv លើ Windows (សម្រាប់ Mac/Linux ប្រើ source venv/bin/activate)។
  • pip install requests (ដំឡើង Library)៖ ដំឡើងកញ្ចប់ requests សម្រាប់ធ្វើការជាមួយ REST API។

មុខងារ API Requests សំខាន់ៗ:

  • requests.get(url) (GET)៖ ទាញយកទិន្នន័យពី Server។
  • requests.post(url, json=data) (POST)៖ បញ្ជូនទិន្នន័យថ្មីទៅកាន់ Server។
  • res.status_code & res.json() ៖ ពិនិត្យលេខកូដស្ថានភាព (ឧ. 200 ជោគជ័យ) និងបំប្លែងទិន្នន័យ JSON ទៅជា Dictionary។

3. Syntax (ទម្រង់កូដ):

import requests

res = requests.get("https://jsonplaceholder.typicode.com/users/1")
if res.status_code == 200:
    data = res.json()
    print(f"Name: {data['name']} ({data['email']})")

4. Output (លទ្ធផលនៅលើ Terminal):

Python Programming 22. Database Integration (SQLite CRUD)

22. Database Integration (SQLite / MySQL CRUD)

1. Definition (និយមន័យ):

Python មាន Module ភ្ជាប់មកជាមួយស្រាប់ឈ្មោះ sqlite3 សម្រាប់ភ្ជាប់ និងគ្រប់គ្រង Database ដោយអនុវត្តប្រតិបត្តិការ CRUD តាមរយៈភាសា SQL។

2. មុខងារ និង Methods សំខាន់ៗ:

  • sqlite3.connect("db") (ភ្ជាប់ DB)៖ បង្កើត ឬភ្ជាប់ទៅកាន់ឯកសារ Database ហើយ conn.cursor() បង្កើតតួបញ្ជា SQL។
  • cur.execute(sql) & conn.commit() ៖ ដំណើរការពាក្យបញ្ជា SQL និងរក្សាទុកការកែប្រែចូលក្នុង Database ជាអចិន្ត្រៃយ៍។
  • cur.fetchone() / cur.fetchall() ៖ ទាញយកទិន្នន័យ ១ ជួរ ឬទាំងអស់ពី Database រួចបិទដោយប្រើ conn.close()។

ប្រតិបត្តិការ CRUD ទាំង ៤ ក្នុង SQL:

  • C - Create (បង្កើត/បញ្ចូល)៖ ប្រើ INSERT INTO ដើម្បីបញ្ចូលទិន្នន័យថ្មីទៅក្នុង Table។
  • R - Read (អាន/ទាញយក)៖ ប្រើ SELECT ដើម្បីទាញយកទិន្នន័យមកបង្ហាញ។
  • U - Update (កែប្រែ)៖ ប្រើ UPDATE ... SET ដើម្បីកែប្រែទិន្នន័យដែលមានស្រាប់។
  • D - Delete (លុប)៖ ប្រើ DELETE FROM ដើម្បីលុបទិន្នន័យចេញពី Table។

3. Syntax (ទម្រង់កូដ):

import sqlite3

conn = sqlite3.connect("school.db"); cur = conn.cursor()
cur.execute("CREATE TABLE IF NOT EXISTS students (id INTEGER PRIMARY KEY, name TEXT)")
cur.execute("INSERT INTO students (name) VALUES (?)", ("លាត ប្រុស",)) # Create
conn.commit()
print(cur.execute("SELECT * FROM students").fetchall())               # Read
conn.close()

4. Output (លទ្ធផលនៅលើ Terminal):

Terminal: python db.py
[(1, 'លាត ប្រុស')]
5. Summary (សង្ខេបមេរៀន)៖ ត្រូវហៅ conn.commit() រាល់ពេលបញ្ចូល កែប្រែ ឬលុបទិន្នន័យ និងប្រើ ? (Parameterized Query) ដើម្បីការពារ SQL Injection។

Python Programming 23. Building Basic REST API (FastAPI)

23. Building Basic REST API (FastAPI)

1. Definition (និយមន័យ):

REST API គឺជាស្ពានភ្ជាប់ទំនាក់ទំនងសម្រាប់បញ្ជូនទិន្នន័យជាទម្រង់ JSON រវាង Backend (Server) និង Frontend (Web/Mobile)។ នៅក្នុង Python គេនិយមប្រើ FastAPI ព្រោះវាមានល្បឿនលឿន និងងាយស្រួលសរសេរ។

2. មុខងារ និងពាក្យបញ្ជាសំខាន់ៗ:

  • pip install fastapi uvicorn (ដំឡើង)៖ ដំឡើង Framework fastapi និង Server uvicorn សម្រាប់ដំណើរការ API។
  • app = FastAPI() (បង្កើត App)៖ បង្កើត Object កម្មវិធី API មេសម្រាប់គ្រប់គ្រង Routes ទាំងអស់។
  • uvicorn main:app --reload (បើក Server)៖ ដំណើរការ API Server នៅលើម៉ាស៊ីនផ្ទាល់ (Localhost)។

HTTP Decorators សំខាន់ៗក្នុង FastAPI:

  • @app.get("/path") (GET)៖ បង្កើត Endpoint សម្រាប់ទាញយកទិន្នន័យ (Read)។
  • @app.post("/path") (POST)៖ បង្កើត Endpoint សម្រាប់ទទួល និងបង្កើតទិន្នន័យថ្មី (Create)។
  • @app.put("/path") (PUT)៖ បង្កើត Endpoint សម្រាប់កែប្រែទិន្នន័យដែលមានស្រាប់ (Update)។
  • @app.delete("/path") (DELETE)៖ បង្កើត Endpoint សម្រាប់លុបទិន្នន័យចេញពីប្រព័ន្ធ (Delete)។

3. Syntax (ទម្រង់កូដ - main.py):

from fastapi import FastAPI
app = FastAPI()

@app.get("/items")
def read_items(): return {"msg": "ទាញទិន្នន័យ (GET)"}

@app.post("/items")
def create_item(): return {"msg": "បង្កើតថ្មី (POST)"}

@app.put("/items/{id}")
def update_item(id: int): return {"msg": f"កែប្រែ ID {id} (PUT)"}

@app.delete("/items/{id}")
def delete_item(id: int): return {"msg": f"លុប ID {id} (DELETE)"}

4. Output (លទ្ធផលនៅលើ Browser / API Response):

PUT http://127.0.0.1:8000/items/1
{"msg": "កែប្រែ ID 1 (PUT)"}
5. Summary (សង្ខេបមេរៀន)៖ FastAPI បំប្លែង Python Dictionary ទៅជា JSON ដោយស្វ័យប្រវត្តិ និងមានទំព័រតេស្ត API ស្រាប់តាមរយៈ /docs។
